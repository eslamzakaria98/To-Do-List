# To-Do List App

A simple and responsive To-Do List application built using HTML, CSS, and JavaScript. It helps users manage daily tasks efficiently by adding, completing, and deleting tasks.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and user-friendly interface
- Responsive design for different screen sizes
- Local storage support (if implemented)

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
